# Thai Yoga Massage – by Maggy Bartels

Onepage-Website (statisches HTML, keine Build-Schritte).

- `index.html` – die Seite
- `maggy-thai-yoga-massage.jpg` – Foto

## Online stellen (GitHub Pages)
Settings → Pages → Source: „Deploy from a branch“ → Branch `main`, Ordner `/ (root)`.

## Kontaktformular aktivieren
Das Formular sendet an Formspree. Kostenloses Formular auf formspree.io anlegen und
in `index.html` `DEINE-FORM-ID` durch die eigene ID ersetzen.

## Noch offen
- Text „Über mich“ und Adresse (Platzhalter in eckigen Klammern)
- Impressum und Datenschutzerklärung (Pflicht in Deutschland)
